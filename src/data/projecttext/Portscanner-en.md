# 🔍 Python Port Scanner

**"A minimalist security tool for network analysis."** This script is a lightweight scanner that identifies the status of network ports on a target system. It is designed to gain insight into active services and potential vulnerabilities within a network.

---

## 🎯 The Project
This project serves as a practical exercise in **Socket Programming** with Python. The tool iterates through a specified range of ports and attempts to establish a TCP connection to determine which ports are 'open' and listening for incoming traffic.

---

## 🛠 Technical Highlights

* **Socket Library:** Utilizes Python's native `socket` module for direct communication with network protocols.
* **Zero Dependencies:** Fully functional using only the Python Standard Library, making the tool portable and secure.
* **Error Handling:** Implemented logic to handle timeouts and unreachable hosts, ensuring the script remains stable during execution.
