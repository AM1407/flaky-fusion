# 🔍 Python Port Scanner

**"Een minimalistische security-tool voor netwerkanalyse."** Dit script is een lichtgewicht scanner die de status van netwerkpoorten op een doelsysteem identificeert. Het is ontworpen om inzicht te krijgen in actieve services en potentiële kwetsbaarheden in een netwerk.

---

## 🎯 Het Project
Dit project is een praktische oefening in **Socket Programming** met Python. De tool doorloopt een opgegeven reeks poorten en probeert een TCP-verbinding tot stand te brengen om te bepalen welke poorten 'open' zijn en luisteren naar inkomend verkeer.

---

## 🛠 Technische Highlights

* **Socket-Library:** Maakt gebruik van de native `socket` module van Python voor directe communicatie met netwerkprotocollen.
* **Geen Dependencies:** Volledig functioneel met de Python Standard Library, wat de tool draagbaar en veilig maakt.
* **Foutafhandeling:** Voorzien van logica om time-outs en onbereikbare hosts op te vangen zonder dat het script crasht.

---

## ⚖️ Disclaimer
Deze tool is uitsluitend ontwikkeld voor educatieve doeleinden. Het scannen van hosts zonder expliciete toestemming is illegaal en onethisch. Gebruik dit script alleen op je eigen systemen of binnen een geautoriseerde omgeving.
