# 🪨 Stoned.io – The Digital Rock Adoption Agency

**"Wait... Stoned.io?"** I see you. Don't worry, the title might be a bit of a shock, but take a deep breath: this platform is strictly about the adoption of rocks. Yes, you read that right. No illicit substances here—just honest, hard, geological friendships. At least, that’s what **Dave** — our self-proclaimed geologist and part-time criminal — wants you to believe.

---

## 🎯 The Concept
Stoned.io is a full-stack e-commerce experiment where **storytelling** is the primary driver of the User Experience. The goal was to transform a static webshop into a dynamic narrative, where every interaction contributes to the absurd world of Dave and his 31 unique stones.

---

## 🛠 Technical Deep-Dive

### 1. Dynamic Inventory & Randomization
Instead of a standard SQL database, the backend runs on a custom **JSON architecture**. Using PHP logic, rocks are randomly assigned to users based on four different "Tiers." Whether you choose the budget-friendly *Pebble* or the high-end *Pristine* package, the system ensures a unique match with characters like the backboard-shattering *Shaquille O'Obsidian*.

### 2. State Management via PHP Sessions
To maintain the integrity of the "adoption" process, I implemented robust session management. Once Dave "finds" a stone for you, it is locked into the session. This guarantees that the user remains connected to the exact same character from the shopping basket all the way to the final certificate.

### 3. Payment Gateway Integration (Ko-fi & Stripe)
For transaction handling, I built a hybrid solution. By utilizing dynamic URL parameters, prices and tiers are synchronized with the external gateway. This includes an automated **redirect flow** that brings the user back to the platform for digital "aftercare."

### 4. Dynamic Adoption Certificate
The project culminates in a dynamically generated certificate. This is a smart PHP template that injects data directly from the JSON database, complete with an official disclaimer from Dave (who waives all liability for sand in your carpet).
